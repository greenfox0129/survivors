# 아트 디렉션

## 현재 스타일 — "네온 기하 + 16px 픽셀 + 실루엣 아이콘"

| 층 | 표현 | 이유 |
|---|---|---|
| 월드 | 거의 검정(`#0a0a12`) + 3% 흰 그리드 | 이동감, 대비 |
| 엔티티 | 채도 높은 단색 기하 도형 (원·삼각·사각·마름모·육각·별), 늑대만 16×16 픽셀 스프라이트 | 원작자 첫 요구 "Canvas 기본 도형, 레트로 도트 느낌" — 가장 싸고 가장 또렷하다 |
| 무기 효과 | 무기색 기반 원·호·선, 발톱은 흑백 반전 이미지 | 무기 = 색으로 식별 |
| 표식 | 실루엣 아이콘 (보물 상자, 엘리트 왕관, 플레이어 엠블럼) | 군중 속에서도 의미가 읽혀야 하는 것만 |
| UI | 어두운 슬레이트 패널 + 무기/장신구 색 아이콘 | 게임 화면과 같은 언어 |

참고: Vampire Survivors 도 일부러 투박한 룩을 유지했다 ("make it crappier") — 화려함이 장르의 핵심이 아니다.
([80.lv](https://80.lv/articles/vampire-survivors-developer-on-its-design-sudden-success))

## 원칙

1. **또렷함 > 화려함** — 원작자는 잔상·번짐·반투명을 싫어한다. 이펙트는 짧고 경계가 분명하게.
2. **색 = 정보** — 무기색·장신구색·적색은 UI와 캔버스에서 같은 값(단일 출처)을 쓴다.
3. **아이콘은 실루엣 한 가지 색** — game-icons.net 스타일(굵은 단색 실루엣)로 통일. 다른 스타일 아이콘을 섞지 않는다.
4. **저사양 우선** — 그림자·블러 대신 외곽선 1px, 그라디언트 대신 캐시된 스프라이트.
5. **픽셀 아트는 16×16 계열** — 기존 늑대와 같은 해상도. 확대는 `image-rendering: pixelated`.
