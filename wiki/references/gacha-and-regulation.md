# 가챠 설계 관행과 한국 확률형 아이템 규제

## 현재 구현

- 재화: **게임 내에서만 얻는 골드** (유료 결제 없음)
- 풀 안에서 **균등 확률**, 등급·천장 없음, 중복 → 기억(돌파 재료)

## 천장(Pity) 관행

| 용어 | 의미 |
|---|---|
| 하드 천장 | N회째에 확정 (예: 90회) |
| 소프트 천장 | 특정 횟수 이후 매 회 확률이 올라감 |

대부분의 현대 가챠는 소프트 천장으로 확률을 올리고 하드 천장을 최종 상한으로 둔다. 목적은 극단적 불운 방지와
이용자 불만·규제 위험 완화. ([dotgg](https://dotgg.gg/how-gacha-pity-systems-actually-work-soft-pity-hard-pity-and-the-50-50/), [mwm.ai 용어집](https://mwm.ai/glossary/pity-system))

→ 우리 게임은 캐릭터가 7명뿐이고 균등 확률이라 천장이 필요 없다. 등급(희귀 캐릭터)을 도입한다면 천장을 함께 설계할 것.

## 한국: 확률형 아이템 정보 공개 의무 (2024-03-22 시행)

게임산업진흥에 관한 법률 시행령 개정 (제19조의2, 별표 3의2). ([아주경제](https://www.ajunews.com/view/20240102104711033), [뉴시스 — 해설서](https://mobile.newsis.com/view/NISX20240219_0002630806), [화우 뉴스레터](https://www.hwawoo.com/newsletter/2024_02_20/240220_k_g.pdf))

| 항목 | 내용 (보도 기준 요약) |
|---|---|
| 대상 | **직·간접적으로 유료 구매 가능한** 확률형 아이템. 온전히 무상으로 얻는 것은 제외. 기본 재화라도 유료로 살 수 있으면 대상 |
| 유형 | 캡슐형 · 강화형 · 합성형(컴플리트 가챠 포함) — 유형별 표시 사항이 다름 |
| 천장 | 천장·변동 확률 구조도 공급 정보를 표시 |
| 광고 | 확률형 아이템 포함 사실 표시 |
| 예외 | 청소년/일반게임제공업 게임물, 등급분류 예외 게임물, 3년 평균 연매출 1억 원 이하 중소기업 게임물 등 |
| 제재 | 위반 시 형사처벌 가능성이 보도됨 (세부는 원문·해설서 확인) |

## 이 프로젝트 체크리스트

- [x] 현재: 골드는 플레이로만 획득 → **공개 의무 대상 아님**

- [ ] 확률을 코드 상수로 두고 화면 표시도 그 상수에서 읽는다 (표시 값과 실제 값이 갈라지지 않게 — 넷마블은 서버 값을 그대로 표시하는 방식, 넥슨은 확률 검증 오픈 API 도입이 보도됨 [뉴스토마토](https://newstomato.com/ReadNews.aspx?no=1224130))
