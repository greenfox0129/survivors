# 레퍼런스 시트 (Reference Sheet)

장르: **Survivors-like / 뱀서라이크 / bullet heaven / reverse bullet hell** — 이동만 직접 하고 공격은 자동,
몰려오는 적을 처치해 레벨업할 때마다 강화 카드를 고르는 로그라이트. 한국 모바일 게임 〈매직 서바이벌〉이 출발점으로 꼽히고
〈Vampire Survivors〉(2022)가 대중화했다. ([Wikipedia: Vampire Survivors–like](https://en.wikipedia.org/wiki/Vampire_Survivors%E2%80%93like))

## 비교 시트

| 게임 | 조작 | 한 판 | 레벨업 선택 | 빌드 핵심 | 메타 성장 | 특징 / 우리에게 주는 시사점 |
|---|---|---|---|---|---|---|
| **이 게임 (Survivors Proto)** | 이동만, 자동 공격 | 무제한(생존형) | 3지선다 + 리롤 | 무기 Lv8 + 짝 장신구 → 진화 | 골드 뽑기·캐릭터 레벨/각성/돌파·특성 | VS 구조 + 모바일식 캐릭터 수집 메타의 혼합 |
| Magic Survival (LEME, 한국, 모바일) | 이동만 | 짧은 생존 | 스킬 선택 | 마법 스킬 조합 | 있음 | 장르의 원류. VS가 영향을 받았다고 알려짐 |
| **Vampire Survivors** (poncle, 2022) | 이동만 | 스테이지당 약 30분 | 3–4지선다, 리롤·스킵·봉인 | 무기 최대 레벨 + 패시브 → 상자에서 진화 | 골드로 영구 강화(PowerUp), 캐릭터·스테이지 해금 | 1분 단위 웨이브 표, 적 300 상한, 상자 = 진화 보상 |
| Brotato | 이동 + 자동 공격 | 웨이브 20개 | 웨이브 사이 상점 | 무기 6개 + 아이템 상점 빌드 | 캐릭터 해금 | 웨이브 사이 "정비 시간"이 리듬을 만든다 |
| 20 Minutes Till Dawn | **수동 조준** | 약 20분 | 업그레이드 트리 | 시너지 강한 업그레이드 | 해금 | 조작 개입을 늘린 변주 |
| Halls of Torment | 이동 위주 | 길고 느린 템포 | 선택지 | **장비**를 들고 시작 | 장비·성장 | 디아블로풍 분위기, 넓이보다 깊이 |
| HoloCure (무료 팬게임) | 이동(+조준 옵션) | 스테이지형 | 3지선다 | 무기 콜라보(합성) | 캐릭터 대량 로스터 | 캐릭터 수집이 동기 — 우리 뽑기 메타와 가까움 |
| Survivor.io / 탕탕특공대 (모바일) | 이동만 | 짧은 스테이지 | 3지선다 | 스킬 진화 | **스태미나 + 장비 가챠** | 장기 서비스형 수익화 변주 ([게임제너레이션](https://www.gamegeneration.or.kr/article/d0bf094f-c889-4550-81aa-6262f112f718)) |

## 장르 공통 문법 (체크리스트)

| 문법 | 이 게임 |
|---|---|
| 자동 공격 + 이동만 조작 | ✅ |
| 레벨업마다 소수의 무작위 선택지 | ✅ 3개 |
| 선택지 조작 수단 (리롤/스킵/봉인) | 리롤만 ✅ |
| 무기 + 패시브 조합 → 진화 | ✅ (단, 진화 후 수치 문제 — known-issues) |
| 시간에 따라 적 구성·밀도 상승 | ✅ 연속 스폰 |
| 정해진 시각의 보스/이벤트 | ❌ (엘리트만) |
| 목표 시간(승리 조건) | ❌ |
| 판이 끝나도 남는 영구 성장 | ✅ 골드·캐릭터·특성 |
| 보물 상자 = 특별 보상 순간 | ✅ (즉시 레벨업 1회) |
