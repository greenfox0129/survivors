# UI 흐름 (Screens & HUD)

> 코드: `src/App.tsx`, `src/ui/**` · 스크린샷: [design/screenshots](../design/screenshots/)

## 화면 전환

```
              ┌──────────── Lobby ────────────┐
              │ 게임 시작 · 캐릭터 뽑기 · 캐릭터 관리 │
              │ 특성 · 도감 · 업적               │
              └──┬──────┬──────┬──────┬──────┬──┘
   GameCanvas ◀──┘  Gacha  Characters Traits  Codex/Achievements
   (게임오버 → 다시 시작 | 로비로)   (← 로비로)
```

`App.tsx` 가 `screen` 상태 하나로 전환하고, 세이브(`SaveData`)를 들고 있다가 각 화면에 내려준다.
로비로 돌아올 때마다 `loadSave()` 로 다시 읽는다.

## 인게임 (GameCanvas)

| 영역 | 내용 |
|---|---|
| 상단 바 | 경험치 바 (시안) |
| 좌상단 | 생존 시간 · 처치 · 스코어 · 레벨(XP 수치) |
| 우상단 | HP 바 (50% 초록 / 25% 노랑 / 그 이하 빨강) |
| 좌하단 | 보유 무기(색 점 + 이름 + Lv/MAX), 장신구(작게) |
| 캔버스 밖 하단 | 조작 안내 · **그래픽: 자동/높음/저사양** 버튼 · 게임 포기 |

- HUD는 엔진이 0.15초마다 보내는 통계로 갱신 (React 렌더 부담 최소화).
- 캔버스는 4:3 비율을 유지하며 `min(960px, 화면 폭, (화면 높이-96px)×4/3)` 로 축소된다.

## 레벨업 모달

LEVEL UP 제목 · 리롤 버튼(남은 횟수) · 카드 3장. 카드 색: 신무기 초록 / 무기 강화 호박 / 진화 금색 / 장신구 보라.
선택하면 즉시 재개. 모달이 떠 있는 동안 캔버스는 정지 화면 1장만 유지한다.

## 게임오버

생존 시간 · 처치 · 레벨 · 스코어 · 획득 골드 · (업적 보상 별). [다시 시작] [로비로 돌아가기].

## 로비

제목/부제/안내문(`gameInfo.ts`), 메뉴 카드 6개(2열), 하단에 조작 안내 · 버전 · (새 버전이 있으면) "새 버전 받기" 링크.

## 도감

탭 4개: 적(등장 시간·스탯·모양) / 무기(레벨별 피해·쿨다운·특수 효과) / 진화(조건) / 장신구(레벨별 효과).
레벨별 특수 효과는 무기 등록표의 `levelEffect` 를 읽어 레벨업 카드와 항상 일치한다.
