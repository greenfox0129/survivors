- 원거리(눈알·해골): 260px 안에 멈추고, 150px보다 가까우면 물러난다. 1.8초마다 직선 탄(속도 240, 판정 반경 5, 그림 반경 10). 탄 피해는 기본 2. 접촉과 같은 분당 배율을 받는다. 동시에 40발. 엘리트는 쏘지 않는다.
- 랜턴: 300초부터 10초마다 1마리. 가중치 풀이 아니다. 움직이지 않고 720px 안에서 같은 탄을 쏜다. 최종 보스가 나오면 멈춘다.
- 박쥐 무리: 70초부터 40초마다 20마리. 반지름 80px인 채워진 원. 체력은 박쥐의 4배, 속도는 2.5배. 속도 흩어짐은 없다. 스폰 때 플레이어 방향을 잡고 그 직선으로만 날아간다. 멀어지면 제거된다.

- 일반 적 속도는 생성 시 ×0.8~1.2 무작위.
- 거리 가속은 없다. 일반 몹은 항상 기본 속도로 움직인다.
- 플레이어에서 1440px 이상 멀어진 적은 제거 (cullFarEnemies).

## 스폰

| 항목 | 값 |
|---|---|
| 첫 스폰 간격 | 0.8s |
| 처음 1분 | 초당 ×0.98 |
| 1분 이후 | 분당 ×0.75. 최소 간격 없음 |
| 최대 동시 적 수 | 120 × (1 + 1 × 경과 분). 0분 120, 1분 240, 2분 360 |
| 잡몹 출현 기간 | 합류 후 180초. 이미 나온 적은 유지. 엘리트·중간보스는 제외 |
| 접촉 피해 쿨다운(적별) | 0.5s |
| 엘리트 주기 | 60s마다 1마리 (상한과 무관). 30초 안에 처치하지 못하면 게임오버 |
| 엘리트 체력 | 250 × 2.1^(5분까지) × 1.7^(그 뒤). 1분 525, 5분 10210, 6분 17357 |
| 엘리트 몸 | 키클롭스 고정. 반경 14×1.8, 속도 50×0.9, 접촉 14×1.5 |
| 생성 시 체력 | 일반 적: 기본 HP × 1.8^(5분까지) × 1.3^(그 뒤). 5분 ×18.9, 6분 ×24.56. 이미 나온 적은 변하지 않음 |
| 생성 시 공격력 | 일반 적: 기본 접촉 피해 × 1.2^(경과 분). 엘리트: 14 × 같은 배율 × 1.5. 이미 나온 적은 변하지 않음 |
| 엘리트 보상 | 보물 상자 → 획득 시 즉시 레벨업 선택지 |
| 중간보스 | 5분 정각, 그 분의 엘리트 대신 1마리. 처치해도 판은 계속. 제한 시간 없음 |
| 중간보스 몸 | 거대 너구리. 체력 200 × 2.1^(5분까지) × 1.7^(그 뒤). 5분 8168. 반경 36. 접근 속도 80, 200px에서 멈춤 |
| 중간보스 돌진 | 길이 400px, 0.1초. 피해 50. 선딜 1초(절반 이하는 3단, 각 0.6초). 후딜 0.8초 |
| 중간보스 접촉 | 50, 0.5초마다. 돌진 피해와 따로. 보상은 보물 상자 |
| 보스 | 10분 정각, 그 분의 엘리트 대신 1마리. 다른 몹은 사라지고 더 나오지 않음. 처치하면 판이 끝남 |
| 보스 몸 | 거대 영혼. 체력 500 × 2.1^(5분까지) × 1.7^(그 뒤). 10분 289942. 반경 48 |
| 보스 피해 | 기본 6 × 1.2^(경과 분) × 1.5. 패턴과 접촉이 같은 값 |
| 보스 후딜 | 체력 60% 초과 1초, 60% 이하 0.5초, 30% 이하 없음 |
