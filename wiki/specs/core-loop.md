# 코어 루프 (Core Loop)

> 수치: [generated/leveling.md](generated/leveling.md) · 코드: `src/game/core/GameEngine.ts`, `entities/Player.ts`, `entities/GemManager.ts`, `systems/upgrades.ts`

## 한 판의 흐름

```
로비 → [게임 시작] → 시작 무기 1개로 출발
   ↓ (적 처치 → 경험치 보석 → 흡수)
레벨업 → 게임 정지 → 3지선다(리롤 가능) → 재개
   ↓ (60초마다 엘리트 → 보물 상자 → 즉시 레벨업 1회 추가)
HP 0 또는 [게임 포기] → 게임오버: 스코어 → 골드 정산, 진화 업적 확인 → 세이브
```

- **승리 조건은 없다** — 끝없이 버티는 생존형. (장르 표준은 "30분 생존 + 보스" — 레퍼런스 참고, 도입 여부는 디자인 결정)

## 이동·카메라

| 항목 | 규칙 |
|---|---|
| 입력 | WASD / 방향키, 대각선은 정규화(속도 동일) |
| 월드 | 경계 없음. 플레이어 시작 (480, 360) |
| 카메라 | 플레이어를 화면 중앙에 고정 (960×720 캔버스) |
| 피격 무적 | 0.6초 (깜빡임 표시) |

## 시간·스코어·골드

- 스코어 = `처치 × 10 + 생존초 × 5`
- 획득 골드 = `floor(스코어 / 10)` (게임오버 시 정산)
- dt 는 프레임당 최대 0.05초로 제한 → 20fps 미만이면 게임 시간이 실제보다 느리게 흐른다.

## 경험치 보석

| 규칙 | 값 |
|---|---|
| 일반 적 처치 | 보석 1개 (가치 1) |
| 엘리트 처치 | 보물 상자 (경험치 0, 획득 시 레벨업 선택지) |
| 흡수 | 흡수 반경 안에 들어오면 280px/s 로 끌려옴 |
| 먼 보석 | 플레이어에서 1152px 이상 → 가장 가까운 보석에 가치 합산 (없으면 경계로 당김) |
| 과밀 | 40개 초과 시 80px 이내 보석끼리 병합 |
| 표시 | 가치 1 파랑 · 2–4 보라 · 5–9 초록 · 10–19 분홍 · 20+ 금색 (클수록 큼) |
| 경험치 배율 | 특성 탐욕 × 돌파 2단계 × 지혜의 결정 |

## 레벨업 선택지 (`systems/upgrades.ts`)

1. **진화 가능한 무기**(최대 레벨 + 짝 장신구 보유)는 항상 맨 앞에 나온다.
2. 남은 칸(총 3칸)은 카테고리 **[무기 강화] [신무기] [장신구(신규+강화)]** 를 동일 확률로 고른 뒤,
   그 안에서 무작위 1개 (같은 선택지 중복 없음).
3. 무기 슬롯 6개, 장신구 슬롯 5개가 차면 해당 "신규" 선택지는 사라진다.
4. 무기 강화 카드는 **다음 레벨에서 얻는 특수 효과**를 보여준다 (예: "2연속 베기").

### 리롤

- 시작 리롤 = 특성 `리롤` 레벨 + (돌파 3이면 +2)
- 생존자 패시브 `extraReroll`: 시작 시 +1, **레벨업마다 +1** (돌파 3이면 각각 +3)
- 리롤 시 3개 전체를 다시 뽑는다.

## 사운드

WebAudio 합성음만 사용 (파일 없음): 히트(30ms 간격 제한), 피격, 경험치(가치에 따라 음높이), 레벨업, 게임오버.
