# src/game/data/ — 밸런스·콘텐츠 데이터 (단일 출처)

게임 수치를 바꾸고 싶으면 **여기만** 고친다. 바꾼 뒤 `npm run docs:spec` 으로 위키 수치표를 다시 만든다.

| 파일 | 내용 |
|---|---|
| `config.ts` | `CONFIG` — 캔버스, **렌더링/성능**(fpsCap, 자동 저사양 기준), 플레이어, 레벨업 곡선, 적 13종·스폰·엘리트, 보석, 무기/장신구 슬롯 수, 장신구 9종, 무기 7종 기본 스탯과 성장률 |
| `evolutions.ts` | `EVOLUTIONS` — 무기별 진화(짝 장신구, 진화 이름·설명, 배율) |
| `progression.ts` | 메타 성장 — 캐릭터(배율·시작 무기·패시브·각인), 골드 특성, 별 특성, 업적, 뽑기/강화/돌파/각인 비용, 기본 세이브 값 |
| `companions.ts` | 정비 가챠 — 다음 한 판의 동행자 3종, 뽑기 비용, 보호막 |

## 규칙

- 로직 모듈을 import 하지 않는다 (타입 제외). 데이터 → 로직 한 방향.
- 레벨별 특수 효과(예: "Lv4에 2연속 베기")는 각 무기 파일의 `*LevelEffect`/스탯 함수에 있다 — 여기 수치와 함께 본다.
- 결과 수치표: [wiki/specs/generated/](../../../wiki/specs/generated/weapons.md)
