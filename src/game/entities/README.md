# src/game/entities/

| 파일 | 역할 |
|---|---|
| `Player.ts` | 플레이어 생성(캐릭터 배율 반영), 8방향 이동(무한 월드), 경험치·레벨업, 피격·무적 시간, 렌더 |
| `EnemyManager.ts` | 적 스폰(가중치·등장 시간·간격 감소), 엘리트(60초), 5분 중간보스 자리, 기본 속도 이동, 접촉 피해, 피해 처리(`damageEnemy`), 근접 적 탐색, 도형/스프라이트 렌더, 늑대 스프라이트 애니메이션, 컬링 |
| `MidBoss.ts` | 5분 중간보스. 접근, 예고선, 400px 돌진, 절반 이하 3단, 접촉 피해 |
| `FinalBoss.ts` | 10분 보스. 등장 시 몹 제거, 예고와 같은 피격, 처치 시 판 종료 |
| `GemManager.ts` | 경험치 보석·보물 상자 드롭, 자석 흡수, 먼 보석 병합, 과밀 시 근접 병합(40개 상한), 가치별 색 단계 렌더 |

## 메모

- 모듈 수준 상태(`idCounter`, `spawnTimer` 등)는 `reset*()` 으로 초기화된다 — 새 게임 시작 시 `GameEngine.reset()` 이 호출.
- 스프라이트 이미지는 **지연 로딩**한다 (모듈 import 시 DOM에 접근하지 않음 → `scripts/gen-spec.mjs` 가 Node에서 import 가능).
- 장식 효과(엘리트 은은한 채움, 보석 광채, 흡수 반경 표시)는 `isLowQuality()` 일 때 생략.
